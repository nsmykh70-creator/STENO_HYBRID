STENO — архиватор в браузере

Вся работа идёт локально на вашем устройстве (WebAssembly): файлы не покидают браузер. Поддерживаются архивы .stn (STN13). Мультифайловые pack/unpack — в десктопной версии.

Рекомендуются файлы до ~128 МиБ (ограничение памяти вкладки браузера). Уровень max может занимать минуты на больших файлах. Архивы STN15 (pack) открываются в консольных версиях — скачать для Linux / Windows / Android.
