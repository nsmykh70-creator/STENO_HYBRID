# STENO HYBRID v5 — блочный адаптивный гибрид

## Что реализовано

Формат STN5 разбивает вход на независимые блоки (по умолчанию 256 KiB). Для каждого блока измеряется полный размер четырёх представлений и выбирается самое короткое:

1. RAW — исходные байты;
2. RLE — пары «длина-1, значение»;
3. DEFLATE — zlib/DEFLATE;
4. DELTA + DEFLATE — обратимое дифференциальное преобразование байтов по модулю 256, затем DEFLATE.

Это адаптивный выбор режима по каждому блоку. В заголовок каждого блока входят режим, исходная длина, длина payload и CRC32. Общий заголовок содержит magic `STN5`, версию/флаги, длину исходных данных и число блоков.

## Математика выбора

Для блока `x` выбирается

`m* = argmin_m (H_block + |E_m(x)|)`

где `H_block = 13` байт — метаданные блока, а `E_m` — кодирование выбранного режима. RAW включён как гарантированный fallback. Поэтому алгоритм не должен сохранять заведомо более длинный payload только ради применения преобразования.

DELTA преобразует последовательность:

`d[0] = x[0]`, `d[i] = (x[i] - x[i-1]) mod 256`.

Обратное преобразование:

`x[0] = d[0]`, `x[i] = (x[i-1] + d[i]) mod 256`.

## Сборка

Нужны C++17 и zlib:

```bash
g++ -O3 -DNDEBUG -std=c++17 -Wall -Wextra -pedantic native.cpp -lz -o steno_hybrid
```

## Использование

```bash
./steno_hybrid encode input.bin packed.stn [level 1..9] [block_size]
./steno_hybrid decode packed.stn restored.bin
```

По умолчанию level=6, block_size=1048576. Допустимый размер блока 1 KiB..4 MiB.

## Честный статус

Это гибридный контейнер/селектор режимов с DEFLATE backend, а не новый независимый энтропийный кодек. DEFLATE предоставляется системной библиотекой zlib. Этап проверяет адаптивный выбор RAW/RLE/DEFLATE/DELTA+DEFLATE, целостность и накладные расходы. Сам по себе этот результат ещё не доказывает превосходство над zlib, Zstandard или LZMA2. Rust-версия не заявляется: в текущем окружении доступен C++17 и zlib.

Тесты: `python3 -m unittest discover -s tests -v`; бенчмарк: `python3 benchmarks/bench.py`.
