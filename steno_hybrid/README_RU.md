# STENO HYBRID v7

Исследовательский прототип блочного обратимого кодека. Реализация, собранная и проверенная в этой среде, — C++17 + zlib. Rust-компилятор в окружении отсутствует; Rust-версия не заявляется как собранная.

## Новое в v7
- Контекстный XOR-предиктор: предсказание следующего байта по предыдущему байту.
- rANS-кодирование остатка предсказания.
- Дополнительные stride-2 и stride-4 delta-преобразования.
- Адаптивный выбор между RAW, RLE, zlib, delta+zlib, rANS, delta+rANS и контекстными режимами с учётом размера блока.
- CRC32 для каждого блока.

## Сборка

```bash
g++ -O3 -DNDEBUG -std=c++17 -Wall -Wextra -pedantic native.cpp -lz -o steno_hybrid
```

## Использование

```bash
./steno_hybrid encode input.bin archive.stn 6 1048576
./steno_hybrid decode archive.stn restored.bin
```

Последние параметры encode: уровень zlib 1..9 и размер блока 1024..4194304 байт.

## Тесты и бенчмарк

```bash
python -m unittest discover -s tests -v
python benchmarks/bench.py
```

Бенчмарк фиксирует размер STENO, zlib-6 и LZMA-3, внутреннее время кодека (без файлового ввода-вывода) и wall-clock процесса (с запуском процесса и файловым вводом-выводом). Скорость считается по исходному объёму. Все сравнения выполняются на одном и том же входном наборе; это микробенчмарки синтетических данных, а не доказательство преимущества на произвольных файлах.
