# STENO HYBRID v9

Экспериментальный блочный lossless-кодек C++17. Формат STN9 (несовместим с STN8).

## Что нового по сравнению с v8

- Окно LZ77 32 КиБ → 256 КиБ по умолчанию, CLI-параметр `window` 4 КиБ–4 МиБ. Длинные периоды
  теперь видны парсеру: корпус с периодом 45000 байт сжимается с ~100% (v8) до ~0.2%.
- Lazy matching (как в gzip): матч в позиции i откладывается, если в i+1 матч длиннее.
- Run-литералы: серии литералов кодируются одним токеном `2, varint(n), байты`
  (одиночные литералы остаются 2-байтовым токеном `0, байт`).
- Максимальная длина совпадения 258 → 4096.
- Словарь DEFLATE от хвоста предыдущего блока (последние 32 КиБ исходных байтов): raw-DEFLATE
  (windowBits=-15) + deflateSetDictionary/inflateSetDictionary, флаг в заголовке блока.
- Префиктор повторяемости: шаг выборки 3-грамм 16 → 8 (периоды, кратные 8, обнаруживаются),
  таблица отпечатков 2^20 → 2^22 (ложные срабатывания на случайных данных ~1.5% при пороге 7%).

## Сборка

Требуются g++/clang++ с C++17 и zlib:

```bash
g++ -O3 -DNDEBUG -std=c++17 -Wall -Wextra -pedantic native.cpp -lz -o steno9
# опционально, с libdeflate (быстрее; словарные блоки всё равно идут через zlib):
g++ -O3 -DNDEBUG -DHAVE_LIBDEFLATE -std=c++17 -Wall -Wextra -pedantic native.cpp -ldeflate -lz -o steno9
```

## Использование

```bash
./steno9 encode input.bin output.stn [level=6] [block=1048576] [window=262144] [depth=1] [threads=0]
./steno9 decode output.stn restored.bin
```

Уровень zlib: 1–9. Размер блока: 4 КиБ–4 МиБ. Окно: 4 КиБ–4 МиБ. depth: 1–1024 (глубина
просмотра цепочки кандидатов, 1 = поведение v9). threads: 0 = авто (энкод по блокам; байты
архива идентичны при любом числе потоков). Декодер определяет формат
по сигнатуре STN9.

## Важные ограничения

- Это экспериментальная версия, не рекомендуемая для единственного хранения важных данных
  без дополнительных проверок и резервной копии.
- Обработка файла целиком выполняется в памяти; потоковый ввод/вывод ещё не сделан.
- LZ77 — жадный парсер с одним кандидатом на хеш и ленивым сопоставлением; это не match finder
  уровня zstd/LZMA.
- Энтропийный кодер — zlib/DEFLATE (raw, windowBits=-15). Новизна этапа — обратимый
  LZ77-токенизатор, префильтр, run-литералы и словарь между блоками, а не новый энтропийный кодер.
- Результаты на синтетических корпусах по 1 МиБ не доказывают преимущество на произвольных файлах.
- v9/STN9 не совместим с v8/STN8: у версий разные магии заголовка и разные потоки токенов.
