# STENO HYBRID v9 — статус

- [x] C++17, собирается g++ с -Wall -Wextra -pedantic без предупреждений
- [x] Окно LZ77 как CLI-параметр (4 КиБ–4 МиБ, по умолчанию 256 КиБ)
- [x] Lazy matching и run-литералы, максимальная длина матча 4096
- [x] Словарь DEFLATE от хвоста предыдущего блока (raw-DEFLATE, windowBits=-15, флаг в блоке)
- [x] Префиктор повторяемости stride-8, таблица 2^22
- [x] Per-block CRC32, границы/лимиты, флаги, tail-байты — валидация декодера
- [x] 12 round-trip корпусов (включая период 45000, lazy-литералы, два блока с общим заголовком)
- [x] Сетка параметров (уровень × блок × окно) + 6 corruption-кейсов отбраковываются
- [x] Период 45000: ~0.24% против ~100% в v8
- [ ] libdeflate (волна 2)
- [ ] Цепочки кандидатов и rep-коды (волна 2)
- [ ] Streaming I/O, параллельные блоки (волна 2)

## Бенчмарки

Синтетика: 8 корпусов по 1 МиБ, 5 прогонов, медианы — `benchmarks/results.txt|json`.
Реальные файлы (fb2 47М, mixed 10М, walk_coarse/fine 10М, period45k 10.5М, rand 4М):
`benchmarks/zlib_speed_comparison_RU.md` и `benchmarks/v9_vs_v8_RU.md`.
Время — ядро кодека без файлового I/O; zlib/LZMA — in-process Python-вызовы, поэтому
сравнение времени ориентировочное, не строго apples-to-apples.
