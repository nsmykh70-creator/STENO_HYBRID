# STENO HYBRID v5 — статус этапа

## Реализация и проверка
- Собран C++17 бинарник `steno_hybrid` с `-O3`, подключена системная zlib.
- 7/7 тестов прошли: пустой поток, все байты, случайные данные, повторы, числовой delta-набор, многоблочный файл и обнаружение повреждения.
- Каждый тест проверяет точное равенство исходных и восстановленных байтов.
- Контейнер поддерживает независимые блоки 1 KiB..4 MiB; default 1 MiB.
- CRC32 проверяется отдельно для каждого блока; декодер отклоняет некорректные длины, режимы и хвостовые данные.

## Синтетический тест, 1 MiB входа, блок 1 MiB

| Набор | STENO v5 | zlib-6 | LZMA preset 3 |
|---|---:|---:|---:|
| Нули | 1 072 | 1 039 | 284 |
| Периодические | 2 618 | 2 589 | 304 |
| Текст | 3 161 | 3 128 | 344 |
| Случайные | 1 048 609 | 1 048 902 | 1 048 688 |
| JSON | 3 691 | 3 658 | 364 |
| Числовая последовательность | 362 610 | 362 577 | 67 848 |

Все шесть наборов прошли round-trip. Размеры STENO v5 близки к zlib-6, но на этих тестах немного хуже на сжимаемых наборах; случайные данные хранятся компактнее, чем в сравнительных потоках zlib/LZMA, за счёт более короткого контейнерного заголовка. LZMA заметно компактнее на части наборов. Эти результаты не доказывают превосходства над зрелыми кодеками.

Время в `benchmarks/results.json` включает запуск отдельного процесса и запись файлов; это не чистая скорость ядра. Набор синтетический, не заменяет тестирование пользовательских файлов.

## Что изменилось концептуально
STENO v5 больше не использует прежний неэффективный самодельный LZ-токенизатор. Он выбирает на каждом блоке минимальный полный payload из RAW, RLE, DEFLATE и DELTA+DEFLATE. Это осознанный контрольный этап: сначала проверяется польза адаптивного выбора преобразования, затем можно заменить DEFLATE независимым энтропийным ядром и сравнить его по тем же тестам.

## Ограничения
- Энтропийное ядро — zlib/DEFLATE, не собственная реализация ANS/rANS.
- Rust toolchain отсутствует; собран и протестирован только C++17 вариант.
- Формат экспериментальный; CRC32 предназначен для обнаружения случайных ошибок, не для криптографической защиты.
